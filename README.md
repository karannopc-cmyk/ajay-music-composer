# AJAY — Independent Music Composer

A responsive one-page composer portfolio inspired by the reference website shared in the conversation. Includes a cinematic hero, compositions section, composer story, services, process, and contact form.

## Preview locally
Open `index.html` in a modern browser. Internet is required for the Google Fonts and remote Unsplash photography used in this starter.

## Before publishing
1. IMPORTANT: Replace `hello@ajaymusic.example` in `index.html` and `script.js` with Ajay’s real contact email before publishing. The `.example` address is a placeholder and will not receive messages.
2. The featured On & On track is embedded from the official NCS YouTube video. It is not an MP3 hosted by this site; visitors must press Play in the embedded player. Check NCS permissions before using the track in any other way.
3. Replace the sample photography with images you have rights to use.
4. Deploy the folder to Cloudflare Pages or connect a GitHub repository for continuous deployment.

This is a front-end starter, not a production audio-generation engine. The melody generator and MP3/WAV/MIDI export functionality are separate features that can be integrated in a later build.
